# Железный ларёк (Byte Booth)

Уютная 3D-игра про мастера, который собирает компьютеры в маленьком ларьке.

**Играть в браузере:** https://babazazu-game.github.io/byte-booth/

Подходит для компьютера и телефона (лучше в горизонтальной ориентации).

## Что в игре

- Клиенты подходят к окошку и рассказывают, какой компьютер им нужен и сколько готовы заплатить. Можно поторговаться.
- Детали с реальными названиями покупаются в интернет-магазине прямо на мониторе ларька. Цены меняются каждый день, новости подсказывают скачки.
- Сборка на верстаке: сокет, тип памяти, слоты, длина видеокарты, мощность блока питания, винты и кабели. Аккуратная укладка кабелей — пятнашки — даёт больше чаевых.
- Тест на стенде: самотест, игровой балл, температуры. Слабый блок питания может сгореть.
- Апгрейды, чистка от пыли, брак и подделки у частников, блогер, постоянные клиенты, коробки-сюрпризы, ремонт деталей.
- Три района города и цель — стать легендой города. Ларёк можно обустроить: покрасить стены, расставить статуэтки, повесить постеры.

## Управление

- Мышь или палец: нажатия по кнопкам, по деталям и местам в корпусе. На верстаке перетаскивание крутит камеру.
- Клавиатура: `1–4` или `A/D` — зоны ларька, `Пробел` — позвать клиента, на верстаке — подсказки клавиш на кнопках.

## Разработка

Three.js + TypeScript + Vite. Каркас площадки Яндекс.Игр (`yg-core`) подключается
исходниками из соседнего репозитория (см. `vite.config.ts`) и в этот репозиторий
не входит. Поэтому собирать проект из этого репозитория нужно вместе с ним.

```bash
npm install
npm run dev     # http://127.0.0.1:5171
npm run build   # сборка в dist/
```

- `characters.html` — служебный просмотр всех персонажей и статуэток.
- `tools/sim.ts` — прогон экономики без графики.
- Правила проекта для агентов — в `AGENTS.md`.
