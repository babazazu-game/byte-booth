# Инструкции агенту

Все правила проекта — в [`AGENTS.md`](AGENTS.md). Файл один на всех агентов
намеренно: Codex, Cursor и Amp читают `AGENTS.md`, Claude Code — этот файл,
и держать два расходящихся свода правил значит однажды получить два разных
поведения на одном и том же проекте.

Читать `AGENTS.md` целиком перед первой правкой.
